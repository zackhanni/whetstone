title: Lazy initial state for expensive setup
---

`useState(initialValue)` only *uses* `initialValue` on the first render; after that React
ignores it. But if you write a function call there, JavaScript still evaluates it on *every*
render, before `useState` even runs. If that call is expensive, pass a function instead and
React will call it only while initializing.

```jsx
// ❌ readFromStorage() runs on every render; React discards the result after the first
const [state, setState] = useState(readFromStorage());

// ✅ React calls it only on the first render
const [state, setState] = useState(() => readFromStorage());
// (useState(readFromStorage), without parentheses, does the same)
```

In development, StrictMode calls an initializer twice and keeps one result, to catch
initializers that aren't pure. Keep it free of side effects and that's invisible.
